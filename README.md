# 🚀 Sahan Pasindu — Developer Portfolio

A modern cinematic developer portfolio built to showcase my projects, technical skills, and frontend development journey.

This project was developed using React, Vite, Tailwind CSS, GSAP, and Three.js with a strong focus on smooth animations, responsive layouts, and immersive user experience.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

Navigate to the project folder:

```bash
cd your-repository-name
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```bash
http://localhost:5173
```
